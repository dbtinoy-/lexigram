# Configuration

`lexigram-contracts` is a **pure protocol and type definition package** with no runtime behavior and no configuration.

- Zero dependencies
- Zero runtime code
- Zero configuration required

The contracts layer is imported and used by `lexigram` and all extension packages. There are no config keys, no environment variables, and no settings to manage.

:::note
If you are looking for the framework configuration system, see the [`lexigram` CONFIGURATION.md](/packages/lexigram/CONFIGURATION/).
:::
